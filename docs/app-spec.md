# Hello iPhone — 首次流程驗證規格

自然語言需求：「做一個簡單 iPhone App，首頁有歡迎文字與大按鈕，點擊次數保留在手機，支援直橫向並顯示版本。」

固定識別：`com.aifactory.helloiphone.a7e4c921`；名稱 `Factory Hello`；初版 `1.0.0`；iOS 17.0 起；iPhone 專用。

驗收：首次開啟為 0；每次點擊加 1；關閉重開保留；旋轉後可繼續操作；畫面有版號。第二版本更新不清除計數。沒有登入、後端、付費、裝置識別或敏感權限。

單元測試：空儲存初值、跨 store 保存、整數溢位邊界。UI 測試：首頁與點擊、重新啟動後保存、橫向操作及截圖。測試儲存區與正常使用資料隔離。

此規格與測試仍需 GitHub macOS 實際編譯驗證；Simulator 通過不等於實機通過。
